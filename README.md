# UVEG-Reto-5-Git-GitHub
Practica de control de versiones para el Reto 5 de la UVEG
## Objetivo

Practicar el uso de Git y GitHub para administrar las versiones de un proyecto.

## Actividades

- Crear un repositorio remoto.
- Clonar el repositorio en la computadora.
- Modificar y guardar archivos.
- Crear ramas para realizar pruebas.
- Integrar cambios en la rama principal.

## Pruebas

Se realizan modificaciones en esta rama antes de
integrarlas a la version principal del proyecto.

Cambio de prueba realizado en la rama pruebas.
